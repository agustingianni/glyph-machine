The Game of Life in a font

Conway's Game of Life, computed by a font. The page holds only the first generation, as one line of text. The font's GSUB table works out the next 120. Click or drag on the board to draw your own.

What the page holds: generation 0, column by column
GSUB chain rules count the neighbors 3 passes per generation FeatureVariations: TIME picks the generation COLRv0 colors: born, alive, just died

The page never computes a generation. It stores generation 0 and sets the TIME axis, and for generation g the font switches on 3 × g lookups. In each generation, one pass counts every cell's live neighbors above and below. Two more passes add the counts from the columns to its left and right, which sit a whole column away in the text. That is up to 360 lookups over about 1,000 glyphs, every time the generation changes.
