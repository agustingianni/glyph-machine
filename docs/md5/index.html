A font that computes MD5

Type a message. While your browser lays out the text, the font works out its MD5 hash and draws the 32 hex digits. All 64 rounds of MD5 run inside the font. The page's JavaScript only checks that the input is printable ASCII.

Each browser gets a font made for its own text engine. Firefox runs Graphite, a rule language with a small integer machine. That font keeps MD5's 16 message words and 4 state words as numbers on one glyph, and revisits the glyph 128 times. Safari runs Apple's AAT morx state machines, which have no numbers, only glyphs and a small state. That font first grows the text into a tape of 704 glyphs, one per bit. Then 2,180 state tables add, rotate, and copy bits along the tape, and keep each carry in the machine's state. The page puts a few invisible characters around your text, so even an empty message has something to shape. Chrome runs neither font.
