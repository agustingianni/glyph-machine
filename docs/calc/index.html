A font that does math

Type a sum like 12+34. Both boxes hold the same text, and only the font changes it. Whole numbers from 0 to 99 with +, -, and *, worked left to right like a pocket calculator. A result outside 0 to 99 shows E.

GSUB ligatures do the math One pass per operator, leftmost first Seven-segment glyphs drawn from scratch Copy the result and your text comes back

First, ligature passes join typed digits into one number glyph. Then each pass replaces the leftmost [number, operator, number] with the glyph for the result. The answer only ever exists as a drawn glyph: select it and copy, and you get your original characters back.
