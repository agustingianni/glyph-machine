GLYPH MACHINE

Fonts that draw impossible things

Six small experiments where a line of text does something a font is not supposed to do. Every scene lives inside a font file and is drawn by your browser's own text engine. No image, canvas, or SVG. The spinning letters above are text too.

Landscape

Mountains scroll past as the sun sets and rises. One letter.

Plasma

A pulsing, swirling demoscene plasma made of 256 dots.

Spinning 3D type

Wireframe 3D letters and a tumbling cube. Type a word and it spins.

Calculator

A seven-segment font whose GSUB table evaluates 12+34.

Game of Life

Conway's Life, worked out by the font's GSUB table. Draw your own.

MD5 hash

Type a message and the font draws its MD5 hash. Safari and Firefox.

Built with fontTools. Chrome and Firefox shape text with HarfBuzz, and Safari uses CoreText. Safari does not draw COLRv1 color fonts, so it shows flat colors instead of gradients. The MD5 demo needs Firefox's Graphite engine or Safari's AAT engine, so it does not run in Chrome. Source for every font is in src/ on GitHub.
