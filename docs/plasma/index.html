A plasma field in one letter

A single letter of text. A grid of 256 dots pulses and swirls, the classic demoscene plasma, computed inside the font by interpolating between 25 time-step masters. A color wheel turns underneath.

time: auto
Variable font, one TIME axis 256 round dots sized by summed sine waves COLRv1 sweep gradient that turns with time The motion is glyph interpolation

A CSS keyframe sweeps the TIME axis; the browser interpolates the masters so the dots flow. The gradient's rotation is a variable paint on the same axis. Without COLRv1 the dots take the text color.
